# VELOUR — AI Instagram DM Automation 

An intelligent messaging system built for **VELOUR Premium Clothing**. This bot uses **Python, Flask, and Groq (LLaMA 3)** to handle customer inquiries instantly.

## ✨ Features
* **AI Responses:** Integrated with Groq API for natural conversation (English + Urdu).
* **Brand Knowledge:** Automated handling of size guides, pricing, and policies.
* **Real-time Webhook:** Processes DMs via Meta Graph API v18.0.

## 🛠️ Tech Stack
* **Backend:** Python / Flask
* **AI Engine:** LLaMA 3 (Groq SDK)
* **API:** Meta Messenger API
* **Tunneling:** ngrok

## ⚙️ Setup
1. Clone repo: `git clone https://github.com/YOUR_USERNAME/velour-ig-bot.git`
2. Install: `pip install -r requirements.txt`
3. Configure `.env` with your API Keys (Meta & Groq).
4. Run: `python app.py`
